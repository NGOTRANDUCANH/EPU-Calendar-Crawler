# 🚀 Tool Cào Lịch Học EPU -> Google Calendar (Bản V5 Bất Tử)

Tool viết bằng JavaScript giúp sinh viên Đại học Điện Lực (EPU) tự động trích xuất lịch học từ hệ thống ASC và đồng bộ thẳng vào Google Calendar chỉ với vài thao tác.

## ✨ Tính năng nổi bật (Bản V5 Pro Max):
* **Cào liên hoàn:** Lưu trữ giỏ hàng, gom lịch học của toàn bộ học kỳ mà không bị sót.
* **Auto nhắc bài:** Tự động cài đặt báo thức nhắc nhở vào lúc **21:00 tối hôm trước** ngày đi học (không bao giờ sợ cúp cua quên giờ).
* **Bất tử thời gian:** Xử lý mượt mà các mốc thời gian vắt năm, giao thừa, năm nhuận.

## 🛠️ Hướng dẫn sử dụng:

**Bước 1:** Đăng nhập vào trang xem lịch học của EPU. Tick vào ô **"Tất cả"** để hiện lịch (Nhớ ấn nút "Hiện tại" hoặc "Lọc" để lịch tuần thò ra nhé).
**Bước 2:** Ấn `F12` trên bàn phím, chuyển sang tab **Console**.
**Bước 3:** Copy toàn bộ code trong file `tool-cao-lich-v5.js` ở kho này, dán vào Console và ấn `Enter`.
**Bước 4:** Để gom lịch của cả học kỳ:
- Trên web, bấm nút `[ Tiếp > ]` để sang tuần tiếp theo.
- Dưới Console, ấn phím mũi tên `Lên ⬆️` (để gọi lại lệnh) rồi ấn `Enter`. 
- Lặp lại cho đến khi hết học kỳ.
**Bước 5:** Sau khi gom xong, gõ lệnh `xuatLichV5()` vào Console và `Enter`. Một file `.ics` siêu to khổng lồ sẽ được tải về.
**Bước 6:** Mở Google Calendar > Cài đặt > Nhập & Xuất (Import) > Chọn file vừa tải về và tận hưởng thành quả! =)))
